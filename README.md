# Autoškola jednoduše

## Cíl
Usnadnit přípravu na řidičský průkaz pomocí krátkých lekcí, opakování chyb a cvičných testů.

## Funkce a stav
V kontrolovaném souboru `Autoškola jednoduše.html` jsou denní lekce, rychlé učení, procvičování chyb, rozbor výsledků, ukazatel připravenosti a ukládání postupu do localStorage. To dokládá obsah kódu, nikoli nový uživatelský test. Některé zdrojové otázky a vysvětlení jsou označené jako neověřené; před označením databáze za správnou je nutné ověřit znění i odpovědi proti autoritativnímu zdroji.

## Vzhled
Jedna úloha na obrazovce, vysvětlení po odpovědi, velká tlačítka pro telefon. Barevnost dopravních značek: modrá, neutrální asfaltové odstíny, světlý i tmavý režim; písmo Overpass. Vychází z existujícího HTML, nejde o novou změnu designu.

## Obsah a spuštění
Repozitář má `index.html` a `Autoškola jednoduše.html`. Druhý soubor byl obsahově přečten; velký `index.html` nebyl celý načten a shoda obou verzí není potvrzena. Statické soubory lze obsloužit lokálním HTTP serverem. Dokumentovaný vstup v projektovém registru je [GitHub Pages](https://honzavitha.github.io/autoskola/); aktuální dostupnost nebyla touto editací testována.

## Workflow a definice hotového
1. Určit kanonickou variantu obou HTML souborů.
2. Ověřit otázky, správné odpovědi a vysvětlení; nepřevádět odhad připravenosti na garanci složení zkoušky.
3. Vyzkoušet lekci, chybnou odpověď, test a obnovení postupu po zavření prohlížeče.
4. Zkontrolovat mobilní čitelnost a zveřejnit ověřenou verzi.
Hotová verze má ověřený obsah a průchod uvedenými scénáři; tento README jejich splnění nepotvrzuje.
